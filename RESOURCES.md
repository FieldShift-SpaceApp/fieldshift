# Resources

> **SI-assisted:** written with Claude Code (Anthropic) from the team's data source map (live access and license checks of 2026-11-14); human review pending. See [`SI-USAGE.md`](SI-USAGE.md).

Every dataset, resource and tool used by the project. Feeds the submission page ("NASA data used" + "all data, resources and tools") and the Data & Methods page (Story 1.4). Owners: EECOM (datasets) + SURGEON (agronomic sources). Methods live in [`content/methods/`](content/methods/).

**Status:** `selected` = will be used whatever the concept (Epic 2) · `candidate` = inventoried and tested, used only if the concept needs it (decided after `D-001` in [`DECISIONS.md`](DECISIONS.md)). When a candidate is adopted, change its status and fill "Feeds" in the same PR as the code that reads it. Never list a number in the app whose dataset is not here (AGENTS.md §2.5). **"Analysis only (fieldshift-hq), not yet in the app"** in "Feeds" = used in the team's analyses (scripts and tables in the private planning repository `FieldShift-SpaceApp/fieldshift-hq`, checked on 2026-11-14); no app code reads it yet, and no number from it is shown in the app except as cited text on the Data & Methods page. **"Used in `analysis/enso-wheat/`"** = read by the public, reproducible analysis in [`analysis/enso-wheat/`](analysis/enso-wheat/README.md) (scripts download the source at run time; committed results are listed in that folder's README).

**License rule (repo is Apache-2.0):** Apache-2.0 covers our code only. Data or derived data committed to the repo keeps its original license and must be attributed here. Column "In git?" says whether derived data may be committed: **yes** (open license, with attribution) · **no** (non-commercial, restricted or unclear: link to the source or fetch at run time, never commit) · **check** (license not confirmed: confirm on the provider's page before committing).
