## Conventions

1. **Log every AI-assisted change** in the table below, in the same PR as the change (C2). One row per PR or per work block.
2. **"SI-assisted" header** at the top of every file generated or substantially edited with AI:
   - TypeScript/JavaScript: `// SI-assisted: <tool>; review: <name or pending> (see SI-USAGE.md)`
   - Python, shell, YAML: `# SI-assisted: <tool>; review: <name or pending> (see SI-USAGE.md)`
   - Markdown: `> **SI-assisted:** written with <tool>; human review <done by name | pending>.` right below the title
   - Markdown read by GitHub as a template (with front matter): `<!-- SI-assisted: … -->` after the front matter
   - JSON data files (no comments): declared here and in the dataset metadata (`provenance.json`), not in the file.
   When a person reviews the file, they replace `pending` with their name.
3. **Images and videos generated by AI carry a visible watermark** (e.g. "AI-generated" in a corner, readable at the size shown). No exceptions for slides, thumbnails or the demo video.
4. **Audio, code and data generated by AI** are acknowledged in the descriptive text of the submission and in metadata (this file, file headers, dataset provenance).
5. Rules 3–4 and the "no NASA logos, flags or mission insignia" rule (C3) are items of the [submission checklist](docs/submission/checklist.md).

Files tagged retroactively with the header on 2026-11-14 (Story 1.2, AC2): every code file and document generated with AI before this PR (`apps/web/src/**` except shadcn/Next scaffold files, `services/science/**/*.py`, `scripts/*`, `.github/workflows/ci.yml`, `.github` templates, root and folder `README.md`, `AGENTS.md`, `CONTRIBUTING.md`). Files that are pure tool output (`create-next-app`, `shadcn` CLI, `uv init`, lockfiles) are not tagged.
