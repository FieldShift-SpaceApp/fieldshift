# Contracts (`@fieldshift/contracts`)

> **SI-assisted:** written with Claude Code (Anthropic); human review pending. See `SI-USAGE.md` at the repo root.

Data contracts v1.1.0 between the science pipeline and the web app (architecture ADR-4).

- **Source of truth:** pydantic models in `services/science/src/fieldshift/contracts/`.
- `schema/contracts.schema.json`: JSON Schema 2020-12, all definitions in `$defs` (generated).
- `ts/generated.ts`: TypeScript types (generated by json-schema-to-typescript).
- `ts/index.ts`: re-exports + `CONTRACT_MAJOR` (the only hand-written TS file).
- `fixtures/agyear-cases.json`, `fixtures/units-cases.json`: Python ↔ TS parity cases (ADR-7).

```bash
npm run contracts   # at the repo root: pydantic → schema → TS
```

Do not edit generated files by hand: CI fails on drift (`git diff --exit-code`).
